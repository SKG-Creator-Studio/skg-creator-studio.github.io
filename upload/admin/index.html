How to use

  • Pick Home page or All projects page at the top to choose which page you edit.
  • Edit mode: click text and type. Click links, images, numbers and form boxes to change them here.
  • Click a skill bar to move its % with the slider. Click a project card to edit it in Projects.
  • Bigger selects the box around the thing you clicked (a whole card or section) so you can Copy, Move or Delete it.
  • Preview mode: the page works normally (menus, sliders).
  • Save writes the page you are editing (and projects.js). The old version is kept in the backups folder.
  • New images go to the uploads folder.
